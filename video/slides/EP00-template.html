先冻结，再撮合。顺序反了，同一笔钱可能被花两次。
  1. 先看一笔下单请求要经过哪些服务。第一站是 API 网关，它负责验证签名和限流。
  2. 网关放行以后，请求进入风控。风控检查余额够不够，价格有没有偏离太多。
  3. 风控通过，账本服务把这笔钱冻结起来。冻结的钱不能再用于别的订单。
  4. 最后，订单才进入撮合引擎，和对手方配对。
  5. 注意这个顺序：先冻结，再撮合。如果顺序反过来，同一笔钱就可能被花两次。

本集小结

记住三件事

  • 请求按固定顺序穿过网关、风控、账本、撮合。
  • 资金先冻结，订单再进入撮合。
  • 市价单从最优价开始，逐档成交。
  1. 最后小结一下。第一，下单请求按固定顺序，依次穿过网关、风控、账本和撮合。
  2. 第二，资金先冻结，订单再进入撮合。
  3. 第三，市价单从最优价格开始，一档一档往上吃。下一集，我们拆开撮合引擎看看里面的数据结构。
